这是**示例文章**，用来演示博客怎么工作。写一篇新文章只需要两步：

1. 在 `blog/posts/` 放一个 `.md` 文件（文件名建议 `日期-slug.md`）
2. 如果页面没配 `data-repo`，再往 `blog/posts/index.json` 里加一行文件名

页面本身**不需要改**。下面的语法都能直接用。

## 支持的写法

- 列表、`行内代码`、**粗体**、*斜体*
- [链接](https://github.com/Fragmented-Chaos)
- 代码块：

```js
// 代码块会原样保留
function hello(name) {
  return '你好，' + name;
}
```

> 引用也支持。

---

文章里也可以直接写原始 HTML —— 作者是自己人，不需要为了安全把 HTML 屏蔽掉。

## 关于评论

文章底部有评论区，基于 GitHub Discussions，**点了才加载**，不会在打开页面时就拉第三方脚本。
